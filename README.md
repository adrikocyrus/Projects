# Cyrus Personal Portfolio

A responsive personal portfolio built with HTML, CSS and vanilla JavaScript.

## Structure
- index.html
- css/base.css
- js/main.js
- images/

## Run
Open `index.html` in a browser, or use VS Code Live Server.

## Customize
1. Replace the GitHub and LinkedIn placeholder links.
2. Add your profile photo to `images/`.
3. Replace project links with your actual repositories/live demos.
4. Connect the contact form to an email/form backend when ready.
